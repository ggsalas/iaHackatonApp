Build a production-ready, SEO-optimized marketing website for Techwix, a technology company. The site will be built using Next.js 15, React, TypeScript, and TailwindCSS, with content pulled from Contentstack. It aims to replicate the design and functionality of a provided reference template.

- Ensure SEO optimization and accessibility compliance
- Create a clean, maintainable codebase with strict TypeScript
